# Nimbus Security Overview

## Encryption
All data is encrypted in transit using TLS 1.3 and at rest using AES-256. Encryption keys are rotated every 90 days through a managed key service.

## Access control
Single sign-on through SAML 2.0 and OIDC is available on the Pro and Enterprise plans. Role-based access control lets administrators restrict dashboards to specific teams. Multi-factor authentication is mandatory for all administrator accounts.

## Compliance
Nimbus is SOC 2 Type II certified and audited annually. The platform is GDPR compliant and offers a data processing agreement on request. Penetration tests are performed by an independent firm twice a year.

## Incident response
Security incidents are triaged within 1 hour and affected customers are notified within 72 hours of confirmation.
